# jianying-editor-skill

剪映 / CapCut 自动化——可以驱动界面，也可以直接写草稿文件。

<sub>Skill · `SKILL.md` + prompts + rules</sub>

---

## 两条路

剪辑软件自动化有两条路，失败方式不一样：

| 方案 | 优势 | 弱点 |
|---|---|---|
| 驱动界面 | 任何版本都能用 | 改版就坏、慢、难验证 |
| 直接写草稿文件 | 精确、快、可 diff | 格式一改就坏 |

这个技能两条都留着，并写明什么时候用哪条。界面路径用于草稿格式表达不了的动作；草稿路径用于一切结构性的东西——片段顺序、时间、转场。

## 覆盖什么

- 草稿工程结构（剪映读取的那份 JSON）
- 片段、轨道与关键帧的表示
- 转场与特效参数
- 文字与字幕时间
- 导出设置

## 目录

```
SKILL.md       方法主体，16 KB
docs/          参考笔记
prompts/       给 agent 的提示词模板
rules/         agent 必须遵守的约束
```

## 用法

把 `SKILL.md` 加载进支持技能包的 agent，再指向一个工程。`rules/` 不是选读——它装着保证生成结果能被载入的那些约束。

## 说明

按写作时的剪映草稿格式验证过。这个格式没有官方文档，而且会变；依赖之前先看 `docs/` 里记录的是哪些版本。
