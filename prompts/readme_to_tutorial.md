# README to Tutorial Prompt

Use this prompt to convert skill README documentation into a step-by-step tutorial.

## Purpose

Convert technical reference docs into beginner-friendly tutorials with:
- Prerequisites
- Step-by-step instructions
- Expected output at each step
- Common errors and fixes
- Complete working example

## Output Format

```markdown
# Tutorial: [Feature Name]

## Prerequisites
- ...

## Step 1: Setup
- ...

## Expected Output
- ...

## Troubleshooting
| Error | Cause | Fix |
|-------|-------|-----|
| ... | ... | ... |
```
